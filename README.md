# Machine-Learning-Pipeline-System
# Titanic Survival Prediction Pipeline 

## Overview
This project demonstrates how to build an end-to-end Machine Learning Pipeline using Scikit-learn for predicting passenger survival on the Titanic dataset.  

The project includes:
- Data preprocessing
- Feature engineering
- Machine Learning pipeline creation
- Model training and evaluation
- Model serialization using `joblib`
- Reusable prediction workflow

---

# Project Objectives
- Understand ML workflow automation using Pipelines
- Apply preprocessing for numerical and categorical features
- Train a Logistic Regression model
- Save and reload trained models
- Build a production-ready ML workflow

---

# Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Pickle

---

# Dataset
The project uses the **Titanic Dataset** containing passenger information such as:
- Age
- Gender
- Passenger Class
- Fare
- Embarked Port
- Family Details

Target Variable:
- `Survived`
